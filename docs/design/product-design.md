# Product Design Notes

Rules for **Station** (Mac desk), **Notch**, **Console**, TAI, and emails. Built on [principles.md](./principles.md).

## Core moment first

Every screen prevents the compromised trade or helps understand it afterward. Cut steps to the aha moment.

## Station workspace window

- **No duplicate session chrome** under the title bar — P&L and risk stay in the menu bar / Notch / pulse elsewhere.
- Rail is navigation only: calm greys, teal for selected row and primary actions only.
- **No template KPI dashboard** — curate metrics; mono numbers with units; fewer larger readable blocks.
- Intervention copy in trader language; calm escalation (nudge → overlay → kill).

## Onboarding, TAI, dashboards, interaction, mobile, visual system, process

See station AGENTS.md invariants and [principles.md](./principles.md). Tokens: `StationDS` in code; web: shadcn + brand tokens. ≤3 type sizes per view; regular weight default.
